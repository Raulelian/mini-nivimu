HR Management System with AI Integration

Mini aplicación web de RRHH para aprender Python, Flask y uso práctico de IA.

---

## 🚀 Funcionalidades actuales

### 👥 Gestión de empleados
- Ver lista de empleados
- Añadir empleados con validaciones
- Eliminar empleados
- Persistencia en archivo JSON

### 🤖 Inteligencia Artificial (Nivel 3)

#### 🟢 Chatbot de RRHH
- Ruta `/chat`
- Responde preguntas sobre el sistema y empleados
- Usa contexto dinámico (número de empleados)

#### 🧠 Procesamiento de texto con IA
Ruta `/procesar-texto`

Permite:
- **Resumir textos** (5–7 líneas)
- **Clasificar textos de RRHH** en:
  - VACACIONES
  - HORARIOS
  - BAJAS
  - OTROS
